## Featured Projects

### 🎓 [Seeds of Future Academy](https://seeds-of-future.com)
Educational management and testing platform for high school students across Scientific, Literary, and Sharia tracks, with secure online quizzes and instant automated grading.

- **RBAC portals** for Admin / Teacher / Student with granular permissions
- **Automated exam engine:** timed MCQ exams, question images, real-time scoring, detailed result breakdowns
- **Exam integrity:** server-side answer protection, submission rate limiting, duplicate-submission prevention
- **Architecture:** MVC with service-layer separation, normalized MySQL schema (10+ tables) with indexing, Redis caching, route throttling, CSRF protection, authorization gates
- **Production:** deployed on Hostinger with custom domain, HTTPS, Vite pipeline, and SEO (sitemap, Schema.org, Search Console)
- **3500+ student exams processed in production**

`Laravel` `PHP 8.3` `MySQL` `Redis` `Bootstrap 5` `Vite`

### 🍽️ [Wajbati](https://wajbati-blue.vercel.app) — Food Ordering Platform
Connects independent home chefs and cloud kitchens with customers: live order management, end-to-end tracking, and native Arabic RTL support.

- **Order state machine:** deterministic lifecycle `Pending → Accepted → Preparing → Ready for Delivery → Delivered → Completed`, with Cash-on-Delivery payment reconciliation
- **Three roles:** customers (filter by diet/cuisine, track orders, rate), chefs (menus, daily capacity limits, accept/reject tickets), admins (partner review, metrics, audit logs)
- **Performance:** optimized indexing, eager loading to prevent N+1 queries, Redis queues for background jobs, self-hosted Vite assets with zero CDN dependencies
- **Security:** CSP / HSTS / X-Frame-Options headers, parameterized queries, role-based policy gates, upload script-execution prevention
- **Quality:** 116+ automated Pest/PHPUnit tests (security policies, commerce logic, order transitions), PSR standards, Laravel Pint + PHPStan

`Laravel 12` `PHP 8.2+` `MySQL` `Redis` `Bootstrap 5` `Alpine.js` `Chart.js` `Vite`
